# Native-media dependency and reproducibility

The shipping default reuses `https://johnofgordon7.github.io/paid-to-raid/dist/` for four large films. This is the same owner's existing Cashfire reference, recorded at source revision `63a6f594f66c353b06d792c7aebbc670784b8e68`. The hosting URL can change; the accepted byte identities cannot. `combat-media-catalog.js` pins each full film's bytes and SHA-256. Each received manifest must match that pinned identity, and every 4 MiB part plus the assembled MP4 is hashed before playback. No film is transcoded or looped. The 17,444,048-byte early-ambush MP4 stays local and is checked by the packaging tests.

The publishable handoff excludes `.bin` video parts already on that host. It retains their complete manifests and all source. The complete local workspace also retains every part and passes reconstruction checks. No part exceeds 4 MiB; the direct MP4 is under 25 MiB.

To create a completely self-contained distribution, run `npm run vendor-media` from a host with access to the public dependency. It fetches only missing/mismatched parts, verifies every part and complete film, and switches the media base to the local distribution. Alternatively copy the matching `assets/video-parts/` directories from the complete media bundle into `dist/assets/video-parts/` and set `mediaBaseUrl` in `dist/combat-media-location.js` to `new URL('./', import.meta.url).href`. Run `npm run check` and the native asset tests, then serve the same `dist/` directory. Local-media asset tests explicitly skip when the intentionally omitted part bytes are absent; the bonus lifecycle/model tests still run. There are no credentials or media-service API calls at runtime.

Footage loading, integrity failures or host deletion never authorise a different prize. The result is chosen before the film. Retry keeps the selected film; Continue reveals the full accepted award. A future design that derives rewards from kill totals needs new action footage or an explicitly redesigned mathematical model. This prototype keeps the inherited reel reward and labels film kills independently.
