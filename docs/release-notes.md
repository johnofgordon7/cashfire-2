# Cashfire 2 v1.5.0

Publication revision 7 adds a synchronized kill and return HUD to both original shooting films. It shows confirmed kills, a running multiplier and the corresponding amount for the accepted stake, or the selected example stake in a free preview. The meter sits beside the contained film on desktop and below it in portrait.

The running values reuse the original Cashfire ladder. Normal advances through 0.5×, 1× and 2×; its fourth kill holds 2× until extraction reveals 5×. Mega advances through 0.5×, 1×, 2×, 5×, 10×, 25×, 50×, 100× and 250×; its tenth kill holds 250× until extraction reveals 1,000×. The terminal hold preserves the final-result reveal order. No future monetary tier is shown.

Pause and media errors hold progress. Retry restarts the film and meter from zero. Skip or recovery Continue reveals the accepted final result while retaining only kills already observed. Return remains the single settlement action. Reopening clears all progress and final text. Free previews use example wording and change no credits or result draws.

The selected artwork, background, all runtime audio, base probabilities, stakes, reel/controller geometry, native footage and payout authority remain unchanged. Native media time drives the HUD, with no additional animation clock. Small kill feedback respects reduced motion.

Current automated, source-frame and archive evidence is recorded separately from unrun rendered browser, audible playback and physical-device checks.
