# Interface contract

The original four-reel layout and IG 1.0.0 control geometry are retained. Keep the game within its viewport with no page scrolling. Header and footer remain persistent; the primary action stays centered independently of optional side controls. All four reels and the reserved result area remain visible.

The stake overlay is anchored to the amount control and contains an internally scrolling three-column grid. Preserve the slider, 18 stake values, modal focus behavior, keyboard controls and compact touch targets. Stake changes are locked while an accepted round is active. Sound and Turbo start off; autoplay uses finite counts and stops on a feature trigger.

Use the included original runtime vectors and Inter font for the shared controls. Game art stays in the play region. Normal and Mega bonuses have distinct titles, colors and reward ceilings. Total returned credits, accepted stake and net result must remain clear. A partial return or break-even result does not use profit celebration.

Reference viewport checks are 320×568, 375×812, 390×844, 430×932, 844×390 and 1194×834. Automated policy checks are separate from rendered or physical-device validation. Review evidence identifies which checks were performed.
